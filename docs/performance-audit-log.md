# Performance Audit Log

This append-only log is generated by `npm run perf:audit`. It records measured
runs from the test-only Electron harness and intentionally excludes raw traces,
vault paths, note content, and user-facing diagnostics. Raw JSON reports and
Chromium traces are written beneath the system temporary directory.

The runner samples Electron process metrics through `app.getAppMetrics()`:
total process CPU, renderer process CPU, GPU process CPU, and working-set
memory. Renderer probes add action wall time, frame gaps, long tasks, DOM
mutations, and node counts. GPU process CPU is not GPU engine utilization; use
the recorded GPU feature status and Chromium trace counters as supporting
evidence only.

A run is comparable only when its profile, build mode, GPU mode, vault shape,
and idle duration are recorded together. Generated fixture content is synthetic
and contains no user data.
