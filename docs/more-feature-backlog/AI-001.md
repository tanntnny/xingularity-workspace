# AI-001 — Add assistive intelligence only around explicit workspace actions

Status: experimental reviewable suggestion helpers.

## Before change

Example: model-assisted behavior was concentrated in note completion, with no shared contract for explainable capture, task, or weekly-plan suggestions.

## After change

`assistiveSuggestions.ts` produces deterministic, source-linked suggestion records with confidence, rationale, and explicit accept/edit/reject state. It can suggest capture triage, task extraction, and weekly-plan actions without auto-applying cross-domain mutations.

## Verification

`tests/assistiveSuggestions.test.ts` covers deterministic suggestions, source references, and explicit action state. Network/model regression fixtures remain future work.
