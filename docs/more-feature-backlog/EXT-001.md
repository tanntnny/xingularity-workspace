# EXT-001 — Provider and plugin ecosystem

Status: experimental manifest validation foundation.

## Before change

Example: a future provider/plugin could declare arbitrary capabilities without a versioned portable manifest or permission checks tied to the provider type.

## After change

`pluginManifest.ts` validates strict semver, portable entrypoints, provider-specific capabilities, least-privilege permissions, network/vault-write requirements, duplicate declarations, and prohibited secret access for note exporters. Invalid manifests return safe field-level errors.

## Verification

`tests/pluginManifest.test.ts` covers valid manifests, unknown capabilities, missing permissions, and unsafe declarations. Loading third-party code is intentionally not enabled by this change.
