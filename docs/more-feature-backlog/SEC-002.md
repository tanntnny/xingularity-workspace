# SEC-002 — Move credentials out of vault settings and define secret scope

Status: experimental device/vault-scoped credential storage.

## Before change

Example: the renderer could save `ai.mistralApiKey` through ordinary vault settings, so a portable vault or settings export could carry provider credential material.

## After change

`CredentialStore` encrypts provider values with Electron safeStorage in app user data, names entries by provider plus resolved vault identity, exposes status without returning secrets, and supports rotation/deletion. Settings strips the legacy key; AI and agent calls resolve credentials only in main. Legacy keys are migrated before any activation-time settings cleanup, and activation fails closed if secure storage is unavailable so the legacy value remains recoverable.

## Verification

`tests/settingsStore.test.ts` and credential code paths verify settings redaction and migration behavior. Portable transfer explicitly excludes credential-like paths and metadata.
