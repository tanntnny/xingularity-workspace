# CAL-003 — Integrate Google Calendar in safe phases

Status: experimental read-only provider adapter.

## Before change

Example: there was no OAuth state, provider connection, selected-calendar list, incremental cursor, ETag, or external event identity.

## After change

`GoogleCalendarAdapter` implements Authorization Code + PKCE state handling, read-only scope validation, token exchange through the device credential store, calendar listing, incremental event sync, cancellation/error mapping, and read-only imported event normalization. Calendar service and preload IPC expose connect, select, sync, disconnect, revoke, and cache deletion operations. Production use requires `XINGULARITY_GOOGLE_CLIENT_ID` and `XINGULARITY_GOOGLE_REDIRECT_URI`.

## Verification

`tests/googleCalendarAdapter.test.ts` covers PKCE, callback validation, read-only scopes, pagination/sync mapping, and error handling. No write scope is requested by this adapter.
