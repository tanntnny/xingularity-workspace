# SEC-001 — Enforce the vault-file protocol boundary

Status: shipped boundary and regression coverage.

## Before change

Example: `vault-file://` could be assembled from a renderer path while the protocol handler owned the final filesystem read. Traversal, symlink, inactive-vault, and MIME boundary behavior was not covered by one protocol-level test.

## After change

`createVaultFileProtocolHandler` receives the active vault scope, permits only approved attachment roots, resolves real paths, rejects traversal and symlink escapes, and returns controlled errors. Valid attachment reads still work without exposing host paths. Tests cover valid reads, parent traversal, encoded traversal, symlinks, missing files, and inactive vaults.

## Verification

`tests/vaultFileProtocol.test.ts` and the node typecheck pass.
