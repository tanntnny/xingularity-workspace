# CAL-004 — Make time, timezone, recurrence, and all-day semantics explicit

Status: shipped normalization primitives.

## Before change

Example: an all-day item and a timed item both flowed through local JavaScript date handling, with no explicit IANA timezone or recurrence validation.

## After change

Date-only ranges remain date-only; timed events require ISO instants and an IANA timezone; event end values are exclusive; recurrence UNTIL values are validated according to all-day/timed mode. DST gaps and ambiguous local wall times are rejected instead of silently shifted.

## Verification

`tests/calendarDomain.test.ts` and the time normalization tests exercise date-only, timed, timezone, recurrence, and task-to-event behavior.
