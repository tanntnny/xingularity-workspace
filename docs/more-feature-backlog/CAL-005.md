# CAL-005 — Finish the calendar workspace hierarchy and interaction contract

Status: experimental visible hierarchy.

## Before change

Example: the route exposed month and week views while the existing day component was not mounted; navigation and period labels only understood month/week.

## After change

Calendar supports month, week, and day modes, persists the selected mode, cycles modes by shortcut, shifts by the correct period, labels the current period, and mounts `CalendarDayView` with accessible task buttons and shared icon-button primitives. Existing month/week shells remain stable.

Calendar unit tests plus typecheck pass. Pointer/keyboard parity and full provider/source filters remain tracked separately from the domain work.
